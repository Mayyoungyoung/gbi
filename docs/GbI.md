# Guide-by-Imagination：多任务强化学习中基于世界模型想象的行为策略裁决

- 日期：2026-08-31（v5）
- 版本：v5（裁决器重构为"Critic 锚定 + 相对想象增益"一元公式；奖励头 two-hot+symlog + 残差加权；TTA 对准奖励头。历史修订记录见附录 B）
- 目标投稿：ICML / NeurIPS / AAAI（CCF-A）
- 工作标题：**Guide-by-Imagination (GbI): Imagination-Based Behavior-Policy Arbitration for Multi-Task Reinforcement Learning**

---

## 0. 一句话定位

**The first imagination-based behavior-policy arbiter for multi-task RL——共享放到动力学层，分化放到行为层。**

世界模型的动力学跨任务共享（MT10 同一机械臂、物理一致、数据可池化），但每任务保留独立策略；运行时由共享世界模型在想象空间中前视推算各候选策略的预期回报，动态裁决"此刻谁该执行"。**指导不再是被学出来的记忆，而是被算出来的选择**（selection-as-search vs. selection-as-memorization）。

方法论坐标系一句话：**架构派（Soft Modularization / PaCo / MOORE）在参数空间妥协，优化派（PCGrad / CAGrad）在梯度空间修补，本方案在行为空间裁决 + 动力学层共享**——参数不共享也不消解冲突，而是在每个决策时刻用想象回答"哪个现役策略此刻最适合任务 i"。

叙事交叉点：**MuZero**（模型内评估候选，Nature 2020）× **CTPG**（跨任务策略指导，NeurIPS 2024，最直接竞品）× **Dreamer**（imagination 机制，ICLR 2020）。GbI 把 MuZero 的"模型内评估候选"从动作级上移到**策略级**，部署到多任务行为指导场景。

三条最硬差异化：

1. 用共享世界模型 + 任务条件奖励头，**在想象中零额外环境交互**给候选策略打分（CTPG 的 guide 需真实交互训练，昂贵且非平稳）；
2. 候选集天然包含自身策略 $\pi_i$ → **拒绝坏指导是涌现性质**，无需 CTPG 的两个显式门控；
3. **不确定性驱动的自适应触发**替代 CTPG 的固定引导步长 $K$。

## 1. 研究目的

### 1.1 明线：CTPG 的三笔账单

CTPG（He et al., NeurIPS 2024）证明"让其他任务策略在本任务中临时接管执行"能显著加速多任务学习，但其指导机制绑定了一支额外的元网络（guide policy），带来三笔账单：

1. **guide policy 训练债**：$\Pi^g_i(j \mid s)$ 需真实交互训练；训练目标因底层行为策略持续切换而**非平稳** → 需要 hindsight correction（补丁）；
2. **policy-filter gate 网络债**：判断"这次指导要不要接受"需要 comparable guide Q 值 → 额外 Q 网络（补丁）；
3. **固定引导步长 $K$ 超参债**：$K$ 过小违背"引导策略应专注一段时间"，过大错过换手时机 → 论文 Limitations 自认需逐环境调参。

三笔账单同源于一个设计选择：**指导决策被实现为"可学习的记忆"**——记忆的学习、校准、触发各自付出代价。

### 1.2 暗线：指导是"记忆检索"还是"前视推算"？

- **记忆检索（CTPG）**：guide 的好坏被历史数据覆盖度绑架；新任务、罕见状态无记忆可查；记忆随策略漂移而过期。
- **前视推算（GbI）**：只要世界模型能向前推演，任何状态都能现算"如果让 $\pi_j$ 接管 $H$ 步会怎样"；推算永远基于现役最新策略，无过期问题。

### 1.3 诚实的 trade-off 立场

GbI 用一个共享世界模型**替代** CTPG 的 learned guide + comparable-Q 机制，代价是引入 model-learning 与 $N \times H$ 想象计算成本（毫秒级，§3.6）。科学立场：**GbI 把 selector-learning 的复杂性，交换成了 world-modeling 的复杂性**——后者是平稳的、可池化数据加速的、且有成熟工程方案（RSSM / TD-MPC2）的学习问题。

## 2. 整体框架

### 2.1 组件总览

| 组件 | 记号 | 数量 | 是否新增 |
|---|---|---|---|
| 任务控制策略 | $\pi_j,\ j \in \{1..N\}$（SAC） | $N$ | 否（沿用 CTPG 设定） |
| 共享世界模型·动力学头 | $\hat P_\theta(s' \mid s, a)$ | 1（ensemble ×5） | **新增**（跨任务共享） |
| 共享世界模型·奖励头 | $\hat r_\theta(s, a, z_i)$（two-hot + symlog） | 1（任务条件） | **新增** |
| 一步 Q 锚 | $Q_{\phi_i}(s, \pi_j(s))$ = 任务 $i$ 自己的 SAC critic | $N$（各 1） | **零新增**（复用） |
| 测试时自适应 | 仅奖励头（可选：残差校准模块） | 按需 | **新增** |

### 2.2 数据流与触发关系

```
                       ┌────────────────────────────────────────┐
                       │      共享世界模型 (RSSM, ensemble×5)    │
                       │  动力学头 P̂(s'|s,a) 跨任务共享          │
                       │  奖励头 r̂(s,a,z_i) 任务条件 (two-hot)   │
                       └──────┬─────────────────▲───────────────┘
                想象 rollout   │                 │ 全体任务 transitions 池化
                (N 候选 × H 步) │                 │ (L1 并集 + L2 自举回流)
                              ▼                 │
 ┌─────────┐  真实交互  ┌──────────────┐        │
 │ 任务 i  │◄───────────│  裁决器 Arbiter│        │
 │ 环境    │───────────►│ ① 一步 Q 锚    │────────┤
 └────┬────┘ (s,a,r,s') │ ② 相对想象增益 │        │
      │                 │ ③ 护栏过滤     │        │
      ▼                 │ ④ argmax 裁决  │        │
 ┌─────────┐            └──────┬───────┘        │
 │ Buffer_i│◄── (s_i,a_j*,s',r_i) 带来源标记 ────┤
 └────┬────┘                   │                │
      │                        ▼                │
      │               j* = i ? 执行 π_i : 执行 π_j*
      ▼                                          │
 SAC_i 正常更新 (critic Q_φi 兼任一步锚) ──────────┘
```

数据流要点：

1. **训练流**：$N$ 个任务各自与真实环境交互 → 各自 buffer $\mathcal{D}_i$ → 并集池化训练共享世界模型（动力学头共享 + 任务条件奖励头）；各任务 SAC 独立更新。
2. **决策流**：触发条件满足时，裁决器对每个候选 $\pi_j$ 先问任务 $i$ 的 critic 一步 Q 值（绝对标尺），再在想象中 rollout $H$ 步算相对增益（§3.2 统一公式），输出 $j_t^*$。
3. **执行流**：$j_t^* \neq i$ 时 $\pi_{j^*}$ 在任务 $i$ 真实执行；产生的真实 $(s_i, a_{j^*}, s', r_i)$ 带来源标记回流任务 $i$ 的 buffer 与世界模型训练集（**L2 自举闭环**：data → model → planning → data）。
4. **触发关系**：奖励头层分歧 $U_{\text{score}}(s)$ 一信号两用——超阈值触发重规划（§3.3）与 TTA 校准（§3.4）；持续高分歧区域触发主动覆盖收集（L3，§3.5）。

## 3. 各模块详细设计

### 3.1 世界模型模块：共享任务条件 RSSM（奖励头 two-hot + symlog）

**结构**。state-based RSSM（参照 TD-MPC2，ICLR 2024，非视频生成式）：确定性隐状态 $h_\tau$（GRU）+ 随机隐变量 $z_\tau$ 构成表征，解码器/预测头输出观测与奖励。工程规格：

- **state/hidden dim：512**（TD-MPC2 默认，state-based 单卡可训）；
- **任务条件 $z_i$**：one-hot 起步，仅注入奖励头；动力学头刻意不注入（转移函数与任务无关）。可升级为 learnable embedding（消融点）；
- **ensemble**：5 成员，同一份池化数据 $\mathcal{D} = \bigcup_i \mathcal{D}_i$，不同随机初始化 + bootstrap 重采样（每成员抽 0.7–0.9 数据子集；可选隐维/学习率微扰动）产生参数多样性。**注意：分歧是被观测的诊断信号，不是被制造的目标**——覆盖充分区域成员应高度一致（$U_{\text{score}} \to 0$ 是好事而非故障），OOD 区域分歧自然放大。v5 效率/归因优化：5 成员**共享动力学，仅在奖励头分叉**，避免分歧混合动力学与奖励头两个来源。

**奖励头的 v5 设计（P1，Phase 0 失败主因的修复）**。Phase 0 诊断定位失败主因在奖励头而非动力学——动力学一步状态 MAE ≈ 0.001–0.002 近乎完美；奖励头在 drawer-close 上 bias +8.57（大于其自身 r_mean 6.88），且为**状态依赖的重尾结构**（饱和平台）。MSE 回归对此类奖励景观失效。修复三件套：

1. **two-hot 分箱回归 + symlog 变换（DreamerV3 式）**：将奖励经 symlog：$y = \mathrm{symlog}(r) = \mathrm{sign}(r)\ln(|r|+1)$ 映射后在分箱上做 two-hot soft-label 交叉熵回归——直接压制饱和平台重尾、消除"高估区"幻觉来源；symlog 同时压缩跨任务奖励尺度差异（3 个数量级 → 免去逐任务 EMA 归一化）；
2. **残差加权采样（替代"只靠 EMA"的被动方案）**：训练样本按其奖励预测残差加权：$w \propto \mathrm{rank}\big(|r - \hat r|\big)$（分位化 sigmoid 权重，每 $T$ 步刷新一次缓存；上限截断防异常重尾样本绑架）。**双流采样**：均匀流训动力学（保住物理覆盖），残差加权流只作用于奖励头梯度，避免重采样扭曲动力学学习；
3. 验收口径：修完立即复测 Phase 0，报告逐任务奖励偏置表（bias / MAE）与 top-1 一致率。

**训练目标**：

$$
\mathcal{L}(\theta) = \underbrace{-\log \hat P_\theta(s' \mid s, a)}_{\text{动力学（跨任务共享）}} + \underbrace{\mathrm{CE}\Big(\hat p_\theta(\cdot \mid s, a, z_i),\ \mathrm{twohot}\circ \mathrm{symlog}(r)\Big)}_{\text{奖励（任务条件，two-hot 交叉熵）}}
$$

**无需专家数据**：世界模型学 $(s, a) \to (s', r)$ 的规律，不学"好行为"；失败、随机探索、次优轨迹对动力学学习与成功轨迹同等有效。state-based 动力学模型万级 transitions 即可起步（与 TD-MPC2 在 MT80 的规模同级），区别于需百万级演示的视频生成式路线。真实风险不在数据量，在冷启动覆盖与跨任务分布差异 → warm-up + 短 horizon + 分歧护栏（§3.3/§3.5）。

### 3.2 裁决器核心：Critic 锚定 + 相对想象增益（一元统一公式，v5 重构）

**问题**：选择器到底听谁的——世界模型想象，还是任务自身的 critic？（v4 P3 的切换式混合需引入 OOD 判定这一额外不确定度量，且引入二值断续，难以归因。）

**v5 答案：一个连续的一元公式，两者分工而非竞争。** 对候选 $\pi_j$：

$$
S_j(s_t) = \underbrace{Q_{\phi_i}\big(s_t,\ a_j\big)}_{\text{① 一步 Q 锚（绝对标尺）}} \;+\; \lambda_t \cdot \underbrace{\Big(\hat I^{(i)}_j - \hat I^{(i)}_i\Big)}_{\text{② 相对想象增益}}
$$

其中 $a_j = \pi_j(s_t)$（SAC 取均值动作降方差）；$\hat I^{(i)}_j = \sum_{\tau=1}^{H-1} \gamma^{\tau-1}\, \hat r_\theta(s^j_\tau, a^j_\tau, z_i)$ 为以 $\pi_j$ 沿共享动力学展开的 $H$ 步想象奖励（$a^j_\tau \sim \pi_j$），自身基线 $\hat I^{(i)}_i$ 同法以 $\pi_i$ 展开。裁决：

$$
j_t^* = \arg\max_{j \in \{1..N\}}\ S_j(s_t)
$$

**为什么这样统一（设计理由）**：

- **① 回答"绝对水平"**：任务 $i$ 的 critic 用真实奖励 TD 训练的，是整个系统里唯一被任务校准过的价值尺子。主实验已证实 QMP（每步 $\arg\max_j Q_i$，零模型裁决）全面最强——critic 的尺子胜过整套想象系统。这不是 CTPG 的 comparable Q：其 guide 是 meta-policy 必须单训一个 Q（补丁）；我们的候选就是真实控制策略，直接问现役 critic 即可，**零新增网络**。
- **② 回答"长程轨迹差异"**：一步 Q 无法区分"起点 Q 相同但后续轨迹分裂"的候选。相对增益只关心两分支想象的**差异**——两个分支共用同一奖励头、同一出发点，早期步共同偏置直接相消；对奖励头的要求从"绝对准"降到"排序准"。**刻意删去 v4 的终端 critic 项**（实测 term_corr 全阶段为负、$\lambda \equiv 0$ 更优）：长程价值已由 Q 锚的 TD bootstrap 承载，想象不再重复估值、只补差分。
- **$\lambda_t$ 校准门（自我校准的信任）**：想象通道只在"相对增益与真实增益正相关"时才被允许影响裁决。用 L2 带真实增益标注的近期状态算 Spearman 相关 $\kappa_t = \mathrm{Spearman}\big(\hat I^{(i)}_j - \hat I^{(i)}_i,\ G^{\text{real}}_j - G^{\text{real}}_i\big)$，取 $\lambda_t = \max(0,\ \kappa_t)$（可加 soft ramp）。$\kappa_t \le 0$ 时系统**平滑退化为纯 QMP**——想象修复失败也不会把裁决拉下水。
- **拒绝坏指导是涌现性质**：候选集含 $j = i$ 时 $\hat I^{(i)}_i - \hat I^{(i)}_i = 0$，自身得分恰好是其 critic 值；若所有外来指导都差，$j_t^* = i$ 自动成立。policy-filter gate 不需要任何额外网络。
- **护栏**：若 $U_{\text{score}}(s) > \tau_{\text{reject}}$（近期分歧 0.99 分位），无论打分如何保持自身策略；换手要求相对增益 $> 0$。

### 3.3 自适应触发机制（分歧在评分层，替代固定 $K$）

**v5 修正**：动力学修好后，v4 的"状态层集成分歧"必然趋近于零而失去触发意义；不确定性信号必须放在**坏过的组件**上。实现上 5 成员共享动力学，仅奖励头分叉——5 个奖励头对**同一想象轨迹**（共享动力学展开，保证轨迹相同）的打分分歧：

$$
U_{\text{score}}(s_t) = \mathrm{Var}_{k}\Big(\hat I^{(i)}_j(s_t)\Big)
$$

**触发**：阈值取近 $W$ 步（$W=10^4$）分歧滑窗的 $\rho$ 分位数（$\rho=0.9$）$\tau_{\text{on}}$——随奖励头变准，分布整体左移，触发率自然下降；无手调阈值。$U_{\text{score}} > \tau_{\text{on}}$ 且当前未处于执行段 → 发起重规划。

**执行段**：保持 CTPG 的问题感知——引导策略需连续执行才能把状态搬运到有意义的区域，故设 $K_{\min}$（起步 3–5 步）为最小执行时长；$K$ 不是全程，仅下限。**设置性质已降级**：$K_{\min}$ 只是防振荡换手的安全阀而非敏感超参（实测 QMP 每步重判体系列最强，短视距裁决本身不劣），$K_{\max}$ 为保守硬上限防模型高估某候选时无限执行——两者构成安全区间，区间内部的真实时长由模型信号决定。提前终止：连续 $m$ 步 $U_{\text{score}} < \tau_{\text{off}} = 0.7\,\tau_{\text{on}}$；Phase 1 对照实验固定 $K$ 时沿用 CTPG 经验值，正式系统用自适应触发（消融：固定 $K$ vs 自适应）。

### 3.4 测试时自适应（AdaJEPA 式，对准奖励头，P2）

承接 AdaJEPA（LeCun 团队，arXiv 2026）哲学：世界模型应在部署闭环中持续校准，而非冻结——其 Plan-Execute-Observe-Update-Replan 闭环对裁决器同样成立。v4 曾把 adapt 对准动力学 `state_head`，但 Phase 0 已证明动力学近乎完美、坏的是奖励头（adapt_loss 恒在 1e-4~2e-3，梯度空转）。**v5 修订**：

1. **目标组件改为奖励头**（可选 + 通往奖励头的最后一层），冻结 GRU/先验/后验——只校准"尺子"，不动"镜头"；
2. **分歧驱动触发**：仅当 $U_{\text{score}} > \tau_{\text{on}}$ 时执行自适应，步数 $\in \{1..3\}$ 按 $U/\tau_{\text{on}}$ 动态；
3. **recent-N 缓冲**（N=5）：复用执行段真实转移（与 L2 回流同源，零额外采集）；
4. 学习率上限 $\text{adapt\_lr} = 0.1 \times \text{wm\_lr}$，防灾难性遗忘；
5. **两种实现（消融）**：(A) 直接梯度更新奖励头权重；(B)（更稳）冻结基础头，测试时拟合一个轻量残差校准模块 $b_i(s)$（仅进打分路径），避免跨任务污染共享头。

**验收口径**：高分歧区 adapt_loss 有意义下降，且裁决后 Phase 0 复测的奖励偏置表收窄。

### 3.5 执行闭环与 OOD 护栏

- **执行期奖励归属**：$\pi_{j^*}$ 在任务 $i$ 真实执行的每一步，一律按任务 $i$ 的真实奖励 $r_i$ 入 Buffer$_i$——数据归属看"在哪个任务的环境里"，而非"谁在动作"；任务 $j$ 的 buffer 不受污染。
- **buffer 来源标记**：每条异策略数据记录 $\{j^*,\ S_{j^*}(s_t),\ U_{\text{score}}(s_t)\}$，供：① 事后分析"想象得分与真实增益相关性"（$\lambda_t$ 校准门的数据来源）；② 审计错误指导案例。
- **off-policy 说明**：SAC 本身 off-policy，异策略数据天然可入 Buffer$_i$（L2 自举的算法前提），无需 importance sampling（若换 on-policy 算法需修正，列入局限声明）。
- **OOD 运行时护栏**：① 悲观修正：$U_{\text{score}}$ 高 → $\lambda_t$ 自动降低（公式自带）；② 拒绝换手：$U_{\text{score}} > \tau_{\text{reject}}$ 时保持自身策略；③ 价值截断：想象 horizon 上限 $H_{\max}$（起步 5），模型误差随步长复合。

**Counterfactual coverage 三级对策**（候选 $\pi_j$ 在任务 $i$ 状态上的 $(s_i, a_j)$ 转移可能从未入池）：

- **L1（零成本基座）**：直接并集 buffer 训练——各任务自身 $(s, a_i)$ 转移必然充足，缺的是跨任务反事实 $(s, a_j)$；
- **L2（在线闭环自举）**：被选中的 $\pi_{j^*}$ 本来就会真实执行——这些 $(s_i, a_{j^*}, s', r_i)$ 是免费的宝贵反事实数据，自动带标记回流。**指导产生数据、数据改善模型、模型改善指导**；
- **L3（主动覆盖收集，可选）**：$U_{\text{score}}$ 持续高的区域，派 $\pi_j$ 做预算封顶的专项短 rollout（每 $10^4$ 步不超 $B_{\text{L3}}$ 步）。

### 3.6 算力预算（$N \times H$ 想象是毫秒级）

$N=10,\ H=5,\ M=5$：每次重规划 $10 \times 5 \times 5 = 250$ 次转移前向（成员并行批处理 → 两次 batch 前向），在 512-dim RSSM 上毫秒级，远小于环境单步仿真耗时；触发频率受 0.9 分位阈值控制（约 10% 步触发），摊薄后想象开销 ≪ 5% 总步时。可分批次预筛 top-$k$ 进一步降 $N$ 因子。

## 4. 已获实验结果与设计反推（v4 → v5 的依据）

Phase 0（两次 NO-GO）+ 主实验的确定性结论，构成了 v5 的全部设计输入：

| 证据（实测） | 反推的设计决策（v5 对应） |
|---|---|
| 奖励头状态依赖重尾偏置（drawer bias +8.57 > r_mean；任务间尺度差 3 个数量级）→ "坏尺子" | two-hot + symlog + 残差加权双流采样（§3.1）；想象只做差分、绝对价值交给真实奖励训练的 critic（§3.2） |
| 动力学一步 MAE 0.001–0.002 → "好镜头" | adapt 目标从动力学迁至奖励头（§3.4）；分歧信号迁至评分层（§3.3） |
| lambda 实验：终端 critic 项与真实回报相关全阶段为负（−0.26 → −0.54），$\lambda \equiv 0$ ≈ 全量 | 删终端价值项；长程价值由 Q 锚 TD bootstrap 承载（§3.2） |
| QMP（每步 argmax $Q_i$）全面最强（0.25 / AUC 0.168） | critic 一步 Q 做绝对锚；想象只贡献相对增益；$K_{\min}$ 可小（一键重判不劣） |
| 同期同质快照下反事实差异≈0（own-policy 最优率 20.8% ≈ 随机 20%；gap 中位数 0.02）→ "空裁决场" | Phase 0 决策场验收前置：**裁决场为空时任何模型修复都是无的放矢**（§5.1） |
| 模型在高差距子集系统性反选（gap≥1.0 时 top1=0.021）；置信度与正确性负相关（−0.287） | 护栏信号必须独立于想象分自身：$U_{\text{score}}$ + 真实预测误差 + $\kappa_t$ 校准门（§3.2/§3.4） |

## 5. 实验设计

### 5.1 Phase 0：决策场 + 尺子验收（生死实验，最先做）

1. **决策场验收（复测前置条件）**：改造候选池使真实差异存在——混合不同训练阶段快照（早/中/晚）× 不同探索温度/超参（复用现有 ckpt，零成本），或冻结快照后继续单独训练拉开差距。通过标准：own-policy 在候选中真实最优比例 **≥ 0.5**；真实 gap 中位数（$\max_j V - V_{\text{own}}$）**> 0.1**；
2. **双轨评估**：分层采样约 $10^3$ 个状态（按任务与训练阶段），用仿真器 `set_state` 复位；真实环境各候选执行 $H=5$ 步得真实 return（多次重复取均值）；世界模型端到端给出 $S_j(s)$；
3. **通过判据**：top-1 一致率 $\ge 0.7$（随机基线 $1/N$）；Kendall $\kappa \ge 0.5$；指导增益配对 $t$ 检验显著为正；附加输出：$\kappa_t$ 校准门曲线、coverage vs top-1 诊断图。

### 5.2 Phase 1–3：机制分层验证

- **Phase 1（固定 $K$ + 统一判官）**：与 CTPG、QMP、Base（独立 SAC）对照，证明"同样调度下 model-based 选择 $\ge$ learned guide"；go 条件：MT10 总成功率不劣于 CTPG 且部分任务显著优于；
- **Phase 2（+ 奖励头修复 + TTA + 自适应触发）**：验证 $U_{\text{score}}$ 与选择误差相关性、TTA 校准收益、$\lambda_t$ 校准门行为；固定 $K$ vs 自适应触发消融；
- **Phase 3（完整系统）**：MT50 / HalfCheetah MT8 规模外推 + L3 主动覆盖。

### 5.3 消融清单

1. 判官公式：纯 QMP（$\lambda_t \equiv 0$）vs 纯想象（去掉①）vs 统一公式（消融连线直接、可归因）；
2. 奖励头：MSE vs two-hot+symlog；残差加权开/关；双流 vs 单流采样；
3. TTA：开/关；对准奖励头 vs 动力学 vs 残差校准模块 (B)；
4. 触发：固定 $K$ vs $U_{\text{score}}$ 自适应（含滞回开/关）；
5. 候选集含/不含自身（验证拒绝涌现）；ensemble 3/5 成员；$H \in \{1,3,5,8\}$ 敏感性；$z_i$：one-hot vs learned embedding。

## 6. 与 CTPG 的对比（精简）

| 维度 | CTPG | GbI（v5） |
|---|---|---|
| 选择信号来源 | learned guide network（记忆） | 想象前瞻推算（search） |
| guide 训练 | 真实交互训练，非平稳 → hindsight correction | 无可学习选择器，零训练成本 |
| 拒绝坏指导 | policy-filter gate + comparable Q（两套机制） | 候选含自身 + Q 锚涌现表达拒绝 |
| 引导时长 | 固定 $K$ 逐环境调参（论文自认） | $U_{\text{score}}$ 自适应触发 + $[K_{\min}, K_{\max}]$ |
| 额外网络 | guide network + comparable Q | 共享世界模型（+ 5 成员）；Q 锚复用现役 critic |
| 尺子可比性 | 两套 Q 需校准 | 单把尺子：任务 $i$ 的 critic 锚 + 相对差分 |
| 失败模式 | selector 非平稳 / 记忆冷启动 | 奖励头偏置 / 空裁决场（分别被 §3.1 与 §5.1 对策覆盖） |
| 可验证性 | 端到端性能 | Phase 0 直接验证"想象排序 ≈ 真实排序" |

## 7. 风险与退路

| 风险 | 后果 | 对策 |
|---|---|---|
| 决策场仍为空（候选差异中位数 0.02，实测） | 模型再好也无指导增益可创造 | 决策场验收为 Phase 0 前置；候选池多样化；仍空 → 转退路 D |
| 奖励头修复后仍不可用（two-hot+symlog 不足以救） | 统一公式退化为 QMP，无想象贡献 | $\lambda_t$ 校准门自动衰减 → 转退路 D；或改 per-task reward head / 相对优势头 |
| $\lambda_t$ 校准门被坏尺子欺骗 | 想象重新主导排名 | $\kappa_t$ 用真实增益标注（L2 回流，非想象分自身）计算；护栏信号独立于想象分 |
| TTA 破坏共享头/跨任务污染 | 其他任务裁决质量下降 | 实现 (B) 残差校准模块；adapt 只在高分歧区且 lr 受限 |
| CTPG 复现低于 base（0.16，待归因） | "三笔账单"叙事失去靶子 | 恢复 fidelity 批次完成归因；叙事退为"统一裁决机制"，不依赖 CTPG 复现质量 |
| Phase 2 分歧与误差相关性弱 | 自适应触发失效 | 退回固定 $K$（Phase 1 已成立可作完整降级论文）；或改用 $\kappa_t$ 排序分歧 |

**显式退路**：

- **候选 D（handoff 退化归因基准）**：若方法路线全部受阻——Phase 0 双根因 + 高差距反选曲线 + QMP 对照 + 决策场诊断本身构成完整 benchmark + 分析型论文，仍占据"跨任务行为指导"夹角；
- **候选 C（难度感知想象预算）**：若全量裁决增益有限——想象/重规划预算按任务难度倾斜分配，机制更轻的短论文；
- 触发条件：Phase 0 复测不达标 → 先评 D；模型成立但增益小 → 评 C。
